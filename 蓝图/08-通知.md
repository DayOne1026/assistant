## WebSocket 管理器（services/connection_manager.py）

```python
class ConnectionManager:
    """按 user_id 管理在线连接，广播即时通知。"""
    def __init__(self): self._conns: dict[UUID, set[WebSocket]] = {}

    async def connect(self, user_id: UUID, ws: WebSocket) -> None:
        """接受连接，加入集合。"""
    async def disconnect(self, user_id: UUID, ws: WebSocket) -> None: ...
    async def send_to_user(self, user_id: UUID, payload: dict) -> int:
        """推给该用户所有连接，返回推送数（在线才推，离线走轮询拉取）。"""
```

WS 鉴权：`/ws?token=<access_token>`，握手前校验，失败 close(1008)。

## Celery 任务（tasks/notification_tasks.py）

```python
@app.task
def scan_due_reminders(limit: int = 100) -> int:
    """Beat 周期任务（每 30s）：扫到期 pending 提醒→逐个 enqueue send_reminder。"""

@app.task
def scan_overdue_todos(limit: int = 100) -> int:
    """每日 9 点：扫 due_at < now 且未完成 todos → send_immediate 超期提醒（主动能力）。"""

@app.task(bind=True, max_retries=3, default_retry_delay=30)
def send_reminder(self, reminder_id: str) -> None:
    """幂等发送：写 notification + WS 推送 + 可选邮件；失败重试。"""

@app.task
def purge_expired_reminders(days: int = 30) -> int:
    """清理过期 cancelled 记录（12 归档）。"""
```

> 适配：Celery 任务函数是同步的，任务内 async 调用（redis/manager/email）用 `asyncio.run(...)` 包同步执行。

`send_reminder` 伪代码：
```
# 幂等：Redis setnx（TTL 5min），失败直接返回
if not await redis.setnx(redis_key("lock", user_id, f"reminder:{reminder_id}"), "1", ex=300):
    return
reminder = get_reminder(reminder_id)
if reminder.status != "pending": return
# 写 notification
nid = create_notification(user_id, "scheduled", channel, title, body, ref)
await manager.send_to_user(user_id, {"type": "reminder", "id": nid, ...})
if channel == "email": await send_email(user_id, title, body)   # 失败重试
reminder.status = "sent"; commit
```

## 测试要点

- 定时提醒：造 notify_at 到期的记录 → 手动跑 scan_due_reminders → send_reminder 幂等只发一次 → notification 落库
- WS：在线用户收到推送；离线用户下次拉取能看到
- 邮件失败重试（mock SMTP）
- 取消后不再发送

## 模块边界

- 提醒注册：07 日程 reminder_at（调 schedule_reminder）
- 自动化规则触发：10（触发时调 send_immediate）
- 发送渠道：ws 本模块实现，email 走 `send_email`（smtp 封装，12 部署配置）
