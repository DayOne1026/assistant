# 05 记忆与知识图谱

长期记忆（PG 偏好）+ 知识图谱（Neo4j 关系）。数据源：对话（04 memory_write）与笔记（06 文档）。

## 数据模型

### user_preferences（PG）
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | UUID | PK | |
| user_id | UUID | FK users.id CASCADE | |
| key | VARCHAR(100) | UNIQUE(user_id, key) | 如 favorite_drink |
| value | JSONB | NOT NULL | 任意结构化值 |
| source | VARCHAR(20) | default 'chat' | chat / note / manual |
| source_conversation_id | UUID | NULL | 来源会话（溯源） |
| created_at / updated_at | TIMESTAMPTZ | TimestampMixin | |

### Neo4j 知识图谱
- 节点标签：`Person, Place, Organization, Topic, Event, Document`（均可带 `Entity` 泛标签）
- 关系：`KNOWS, WORKS_AT, LIVES_IN, LIKES, RELATED_TO, MENTIONS`
- 约束：`(id, user_id)` 复合唯一（03）
- 属性：`id`（业务 id）、`user_id`（强制）、`name`、`type`、`confidence`、`source_conversation_id`（来源会话，溯源）、`created_at`

## Pydantic Schema

```python
class ExtractedTriple(BaseModel):
    """从文本提取的三元组。"""
    subject: str
    predicate: str
    object: str
    subject_type: Literal["Person","Place","Organization","Topic","Event","Document"]
    object_type: Literal["Person","Place","Organization","Topic","Event","Document"]
    confidence: float = Field(ge=0, le=1)

class TripleExtraction(BaseModel):
    """包装顶层 list——多数 SDK 对顶层 list 结构化输出支持不稳，外包一层更稳。"""
    triples: list[ExtractedTriple]

class TripleResponse(BaseModel):
    subject: str
    predicate: str
    object: str
    confidence: float

class MemoryQueryRequest(BaseModel):
    question: str

class MemoryResponse(BaseModel):
    answer: str
    sources: list[str]      # 命中偏好 key / 图路径描述

class MemoryItem(BaseModel):
    key: str
    value: Any
```

EXTRACTOR_LLM = get_chat_model()

`extract_triples` 伪代码：
```
prompt = f"""从文本提取事实三元组(主-谓-宾)，只输出 JSON 数组。
类型限 Person/Place/Organization/Topic/Event/Document。忽略虚指与否定歧义。

```

## GraphWriter（Neo4j）

```python
class GraphWriter:
    def __init__(self, neo4j: Neo4jClient): ...
    async def write_triples(self, user_id: UUID,
                            triples: list[ExtractedTriple],
                            conversation_id: UUID | None = None) -> int:
        """MERGE 写入三元组，返回写入条数。节点/关系带 user_id + source_conversation_id。"""
```

`write_triples` 伪代码：
```
for t in triples:
    await neo4j.execute_write("""
        MERGE (s:`{s_type}` {id: $sid, user_id: $user_id})
        SET s.name = $subject, s.confidence = $confidence,
            s.source_conversation_id = $conversation_id
        MERGE (o:`{o_type}` {id: $oid, user_id: $user_id})
        SET o.name = $object, o.confidence = $confidence,
            o.source_conversation_id = $conversation_id
        MERGE (s)-[r:RELATED_TO {predicate: $predicate, user_id: $user_id}]->(o)
        SET r.confidence = $confidence, r.source_conversation_id = $conversation_id
    """, {"user_id": str(user_id),
          "conversation_id": str(conversation_id) if conversation_id else None,
          "sid": stable_id(user_id, t.subject),
          "oid": stable_id(user_id, t.object), ...})
return len(triples)

def stable_id(user_id: UUID, name: str) -> str:
    """同用户同名实体稳定 id：sha256(user_id|name) 前 32 位。"""
```

## 记忆查询（services/memory_service.py）

```python
class MemoryService:
    def __init__(self, db: AsyncSession, neo4j: Neo4jClient,
                 llm=get_chat_model()): ...

    async def remember(self, user_id: UUID, key: str, value: Any,
                       source: str = "chat",
                       conversation_id: UUID | None = None) -> None:
        """upsert user_preferences。conversation_id 记录来源会话（溯源）。"""

    async def get_memory(self, user_id: UUID, key: str) -> Any | None: ...

    async def query_memory(self, user_id: UUID,
                           question: str) -> MemoryResponse:
        """偏好匹配 + 图多跳 → LLM 组装回答。"""
```

`query_memory` 伪代码：
```
# 1. 偏好检索：LLM 把问题映射为 key，或 LIKE 模糊匹配
candidates = await preference_repo.search(db, user_id, question)
# 2. 图检索：问题中提取实体名 → 多跳
entities = extract_entity_names(question)          # LLM 或正则
paths = []
for e in entities:
    paths += await get_related_entities(user_id, e, max_depth=2)
# 3. 组装上下文
ctx = {"preferences": candidates, "graph_paths": paths}
answer = await llm.ainvoke(f"基于记忆回答：{question}\n记忆：{ctx}")
return MemoryResponse(answer=answer, sources=[...])
```

```python
async def get_related_entities(user_id: UUID, entity_name: str,
                               max_depth: int = 2) -> list[dict]:
    """多跳查询。Cypher 带 user_id 强制过滤（03）。"""
```

`get_related_entities` 的 Cypher：
```cypher
MATCH (start {name: $entity, user_id: $user_id})
MATCH path = (start)-[:RELATED_TO*1..{max_depth}]-(related)
WHERE related.user_id = $user_id
RETURN [n IN nodes(path) | n.name] AS path_names
LIMIT 50
```

## 用户画像快照（user_profiles）

事实层（preferences + 图谱 + 对话）之上的聚合画像——"这个人是谁"，供对话开头注入，避免每次现拼。

### 数据模型（PG）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| user_id | UUID | FK users.id CASCADE, UNIQUE | 一人一份 |
| summary | TEXT | NULL | LLM 画像摘要 |
| structured | JSONB | NULL | {location, profession, interests[], traits[], age_group} |
| facts_count | INT | default 0 | 支撑画像的事实条数 |
| updated_at | TIMESTAMPTZ | TimestampMixin | |

RLS 纳入（03），读取强制 user_id。

### ProfileStruct（结构化输出，三层兜底同 04）

```python
class ProfileStruct(BaseModel):
    location: str | None = None
    profession: str | None = None
    age_group: str | None = None
    interests: list[str] = []
    traits: list[str] = []
    summary: str                 # 一段自然语言画像

class Profile(BaseModel):
    """用户画像读取模型（user_profiles 表）。ProfileService.get_profile 返回它。"""
    summary: str
    structured: dict | None = None
    facts_count: int = 0
    updated_at: datetime
```

### ProfileService（并入 services/memory_service.py）

| 函数 | 职责 |
|---|---|
| `get_profile(user_id) -> Profile | None` | 读 Redis 缓存 `app:profile:{user_id}`，未命中读 PG |
| `mark_stale(user_id)` | 新事实写入后调用：失效缓存 + 脏计数 incr |
| `refresh_profile(user_id) -> Profile` | 取近期事实 → LLM 合并生成 → upsert |
| `invalidate_cache(user_id)` | 清 Redis 缓存 |

`refresh_profile` 伪代码：
```
facts = 近 30 天 user_preferences + 图谱实体/关系采样 + 对话摘要
profile = llm.with_structured_output(ProfileStruct).ainvoke(facts)
upsert user_profiles(user_id, summary, structured, facts_count=len(facts))
invalidate_cache(user_id)
```

### 更新策略

- **增量**：preferences/图谱写入后 `mark_stale`（脏计数 +1）
- **定期重构**：Celery `memory_tasks.refresh_profiles`（每日，或脏计数 ≥ 5 触发）
- **注入**：`PromptAssembler.build_system_prompt`（10）把 summary 注入动态上下文区——会话开头就有画像，不查库
- 语义问答（"我上次说喜欢喝什么"）仍走 query_memory 事实层；画像注入管"AI 认识用户"

### 测试要点

- refresh 生成画像；mark_stale 后缓存失效；读取命中缓存
- 无事实用户：refresh 返回空画像不报错
- 隔离：A 查不到 B 的画像

## Agent 集成（04 的两个节点）

### memory_write（对话后写入）

```python
async def memory_write(state: AgentState) -> dict:
    """提取本次对话三元组写图谱；同时抽取偏好写 PG。失败静默，不阻断。"""
    text = "".join(m["content"] for m in state["messages"] if m["role"] == "user")
    triples = await extract_triples(text)
    await graph_writer.write_triples(state["user_id"], triples,
                                     conversation_id=state.get("conversation_id"))
    # 偏好写入同样带 conversation_id 溯源（memory_service.remember）
    return {"memory_context": f"wrote {len(triples)} triples"}
```

### memory_query

```python
async def memory_query(state: AgentState) -> dict:
    """问题→偏好+图谱→组装 memory_context 注入 finalize。"""
    resp = await memory_service.query_memory(state["user_id"],
                                             state["messages"][-1]["content"])
    return {"memory_context": resp.answer}
```

## 模块边界

- 三元组提取与写入：本模块
- 图谱查询与遍历：本模块（query_memory / get_related_entities）
- 用户上传文档检索：06 RAG（本模块只处理对话/笔记抽取的关系）
- 运行时记忆：04 对话

## 测试要点

- 提取：给定文本 → 三元组结构与类型合法
- MERGE 幂等：同三元组写两次不产生重复节点/关系
- 复合唯一：同用户内实体去重；跨用户同名实体不冲突
- 隔离：A 的图查不到 B 的实体；verify_user_scope 拒绝
- query_memory 无记忆时优雅降级（正常闲聊回答）
