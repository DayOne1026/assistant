# 13 前端（Vue 3）

求职展示的"门面"。完整 Vue 前端：对话 UI、图片展示、工具调用可视化、图片库、日程/任务管理。

## 技术栈

- Vue 3 + Vite + TypeScript
- Vue Router + Pinia（路由守卫 + 登录态）
- UI 库：Element Plus（表单/弹窗/消息/上传）
- 图表：ECharts（工具调用、数据可视化）
- 请求：axios（拦截器：Bearer + 401 自动刷新）
- WebSocket：原生 + 断线重连
- E2E：Playwright

## 页面与后端对接

| 页面 | 对接 API | 要点 |
|---|---|---|
| /login | POST /auth/login、/auth/register | 成功后存 token 跳 /chat |
| /chat | POST /conversations、POST /conversations/{id}/messages、GET messages | 对话；附件图片 `<img src>`；工具挂起 → 确认按钮 |
| /images | POST /images、GET /images、POST /images/search | 网格 + 拖拽上传 + 图查图/文字搜图 |
| /schedule | /schedules CRUD | 列表/日历；删除二次确认 |
| /todos | /todos CRUD + toggle | 勾选完成 |
| /memory | /memory/preferences、/memory/query、/graph/entities、/tool-logs | 偏好 + 图谱可视化（ECharts 力导向图）+ 工具调用日志时间线 |
| /settings | /prompts CRUD | 自定义人设 |

## 关键交互

### 图片展示
- 后端返回的 url 已带短期 token：`<img src="/api/v1/images/{id}?token=xxx">` 直接渲染
- 历史消息/列表：后端在响应里补临时 URL，前端不自己拼 token
- 上传：el-upload multipart，传完刷新网格

### 工具确认（对话内）
- 消息流里检测"待确认：xxx" → 渲染 `ConfirmDialog` → 确认 → `POST /agent/tools/confirm {confirm_latest: true, conversation_id}`
- 取消 → deny（11）

### 流式对话
- 蓝图 04 非流式返回 `ChatResponse`，前端先做非流式（简单稳定）；SSE 流式标注为升级路径

### WebSocket 通知
- 登录后连 `/ws?token=`，收 `{type:"reminder"...}` → ElMessage toast
- 断线重连（指数退避）

### 工具调用可视化
- /memory 页集成 `ToolCallTimeline`：按时间线展示每次工具调用（名称/等级/决策/结果）
- 对接 `GET /tool-logs`（11）；ECharts 时间线或表格
- 对话页消息下方可内嵌单次工具调用卡片（折叠）

## 鉴权流程

```
登录 → Pinia 存 access_token（localStorage 持久）→ axios 拦截器带 Bearer
401 → 调 /auth/refresh 换新 → 重试原请求
refresh 失败 → 清 token 跳 /login
图片 URL token：后端生成（短期），前端不管理
```

## 与后端联调约定

- **dev**：vite `proxy: { '/api': 'http://localhost:8000' }`，同源请求，无需 CORS
- **生产**：Nginx 反代 `/api` → 后端；前端静态文件由 Nginx 托管
- 时间显示：后端 UTC → 前端按 `users.timezone` 转本地
