# 02 认证与用户

JWT access + refresh 轮换、密码策略、账户锁定、token 黑名单、用户信息管理。

## 数据模型（PG）

### users
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | UUID | PK, default gen_random_uuid() | |
| email | VARCHAR(255) | UNIQUE, NOT NULL | 登录账号 |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 展示名 |
| hashed_password | VARCHAR(255) | NOT NULL | bcrypt |
| timezone | VARCHAR(64) | default 'Asia/Shanghai' | 响应时区 |
| is_active | BOOL | default true | 软禁用 |
| is_locked | BOOL | default false | 锁定标记 |
| failed_login_count | INT | default 0 | 连续失败次数 |
| locked_until | TIMESTAMPTZ | NULL | 锁定截止 |
| created_at / updated_at | TIMESTAMPTZ | TimestampMixin | |

### refresh_tokens
| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | UUID | PK | |
| user_id | UUID | FK users.id CASCADE | |
| token_hash | CHAR(64) | UNIQUE | sha256(refresh_token) |
| jti | UUID | UNIQUE | 撤销定位用 |
| expires_at | TIMESTAMPTZ | NOT NULL | |
| revoked_at | TIMESTAMPTZ | NULL | 轮换/登出时写入 |
| created_at | TIMESTAMPTZ | | |

token 黑名单不建表，放 Redis：`jwt:blacklist:{jti}`，TTL = access 剩余寿命（见下）。

## Pydantic Schema

```python
class RegisterRequest(BaseModel):
    email: EmailStr
    username: str = Field(min_length=3, max_length=50, pattern=r"^[a-zA-Z0-9_]+$")
    password: str = Field(min_length=8, max_length=64)   # 策略校验在 service
    timezone: str = "Asia/Shanghai"

class LoginRequest(BaseModel):
    email: EmailStr
    password: str

class RefreshRequest(BaseModel):
    refresh_token: str

class TokenResponse(BaseModel):
    access_token: str
    refresh_token: str
    token_type: str = "bearer"
    expires_in: int                 # access 秒数

class UserResponse(BaseModel):
    id: UUID
    email: EmailStr
    username: str
    timezone: str
    created_at: datetime

class ChangePasswordRequest(BaseModel):
    old_password: str
    new_password: str = Field(min_length=8, max_length=64)
```

    """签发 access token，返回 (token, jti, expires_at)。payload: sub=user_id, jti, exp。"""

    """生成不透明 refresh token，返回 (raw_token, sha256_hex, jti)。"""

## services/auth_service.py

```python
class AuthService:
    def __init__(self, db: AsyncSession, redis: RedisClient): ...

    async def register_user(self, data: RegisterRequest) -> User:
        """唯一性校验(email/username) → 密码策略 → hash → 建用户。"""

    async def login(self, data: LoginRequest) -> TokenResponse:
        """认证 + 锁定检查 + 失败计数 + 签发双 token。"""

    async def refresh(self, refresh_token: str) -> TokenResponse:
        """校验 refresh → 轮换（旧 revoke、发新双 token）。"""

    async def logout(self, access_token: str, refresh_token: str | None) -> None:
        """access jti 入 Redis 黑名单(TTL=exp)；refresh 若给则 revoke。"""

    async def change_password(self, user: User, data: ChangePasswordRequest) -> None:
        """旧密码校验 → 策略校验 → 改 hash → 全量 revoke 该用户 refresh。"""
```

`login` 伪代码：
```
user = await user_repo.get_by_email(db, data.email)
if user is None:
    raise AppException(BAD_CREDENTIALS, "账号或密码错误")
if user.is_locked and user.locked_until and user.locked_until > now_utc():
    raise AppException(ACCOUNT_LOCKED, "账户已锁定")
if not verify_password(data.password, user.hashed_password):
    user.failed_login_count += 1
    if user.failed_login_count >= 5:
        user.is_locked = True; user.locked_until = now_utc() + 15min
    await db.commit()
    raise AppException(BAD_CREDENTIALS, "账号或密码错误")
# 成功：复位计数，签发
user.failed_login_count = 0; user.is_locked = False; user.locked_until = None
await db.commit()
return await self._issue_tokens(user.id)
```

`refresh` 伪代码：
```
h = sha256(refresh_token.encode()).hexdigest()
row = await refresh_token_repo.get_by_hash(db, h)
if row is None or row.revoked_at or row.expires_at < now:
    raise AppException(INVALID_TOKEN, "refresh token 无效")
row.revoked_at = now; await db.commit()
return await self._issue_tokens(row.user_id)
```

`logout` 伪代码：
```
payload = decode_access_token(access_token)          # 含 jti/exp
await redis.set(blacklist_key(payload["jti"]), "1", ex=max(0, payload["exp"] - now))
if refresh_token:
    h = sha256(refresh_token...); row = get_by_hash; row.revoked_at = now; commit
```

`_issue_tokens(user_id)`：
```
access, jti, exp = create_access_token(user_id)
raw, h, rt_jti = create_refresh_token()
insert refresh_tokens(user_id, token_hash=h, jti=rt_jti, expires_at=now+7d)
commit
return TokenResponse(access_token=access, refresh_token=raw,
                     expires_in=settings.access_token_expire_minutes*60)
```

## API 层（api/auth.py、api/users.py）

| 方法 | 路径 | 入参 | 出参 | 说明 |
|---|---|---|---|---|
| POST | /auth/register | RegisterRequest | UserResponse | 注册即登录？否，注册后前端调 login |
| POST | /auth/login | LoginRequest | TokenResponse | |
| POST | /auth/refresh | RefreshRequest | TokenResponse | 轮换 |
| POST | /auth/logout | {refresh_token?} + Bearer | ok | access 黑名单 + refresh revoke |

| POST | /users/me/password | ChangePasswordRequest + Bearer | ok | |
| GET | /account/export | Bearer | JSON 下载 | 全数据导出（日程/任务/偏好/图谱/图片/会话） |
| POST | /account/import | multipart JSON | ok | 恢复导入（校验格式与归属） |

数据导出/导入/注销（services/export_service.py，00 落位）：
- `export_user_data(user_id) -> dict`：聚合 schedules/todos/preferences/图谱三元组/图片元数据/会话历史 → JSON
- `import_user_data(user_id, data) -> stats`：校验格式与归属 → 批量写入（幂等，冲突跳过）
- `delete_account(user_id)`：级联删除（DB CASCADE + Redis 用户 key 清理 + Neo4j 节点清理）

依赖：`get_current_user` 在 deps.py：

```python
async def get_current_user(creds=Depends(oauth2_scheme),
                           db=Depends(get_db),
                           redis=Depends(get_redis)) -> User:
    payload = decode_access_token(creds)
    if await redis.get(blacklist_key(payload["jti"])):
        raise AppException(TOKEN_EXPIRED, "token 已撤销")
    user = await user_repo.get_by_id(db, UUID(payload["sub"]))
    if user is None or not user.is_active:
        raise AppException(INVALID_TOKEN, "用户不存在或已禁用")
    return user
```

## 隔离接入

`get_current_user` 解析出用户后，请求级事务必须调用 `set_tenant_context(db, user.id)`（03）再进入业务查询——在路由层统一做，或封装 `get_current_user_isolated` 依赖：
```python
async def get_current_user_isolated(user=Depends(get_current_user),
                                    db=Depends(get_db)) -> User:
    await set_tenant_context(db, user.id)
    return user
```
